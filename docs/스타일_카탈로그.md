## 0. 왜 이 문서가 생겼나

가이드를 만든 뒤 게임들이 **새로운 한 가지 틀로 굳었다.** 열기구 우편 비행, 울림 밴드, 지구 궤도 관제사, 빛줄기 서커스가 모두 같은 그림이었다. 3단 셀음영 + 진한 외곽선 + 종이 결에, 크림 종이·놋쇠·빨간 도장 UI를 썼다. 이름만 수채·종이 공작·네온으로 달랐다.

영상 8개에서 얻은 결론은 다섯 가지다.
1. **장르가 그림체를 정하지 않는다.** 디펜스 하나도 굵은 외곽선 카툰(킹덤 러시), 어두운 픽셀(The Last Spell), 로우폴리 섬(Thronefall), 하얀 미니멀 섬(Bad North), 카드 일러스트(나인 킹즈), 광택 3D(블룬스 TD 6)로 갈린다.
2. **그림체는 6축의 조합이다.** 같은 복셀도 낮(Autonomica)과 네온 밤(Nivalis)이면 다른 게임이다. 축 하나만 바꿔도 달라 보인다.
3. **배운 만큼 세계가 바뀌면 재미있다.** 구름이 걷히고(Dragon Shelter), 꽃밭이 채워지고(Blossom's Grove), 가게가 늘어난다(카이로소프트).
4. **아이용 게임은 크고 단순하고 과장된다.** 큰 실루엣, 원색, 과장된 표정, 시상대·배지 같은 보상 공개(닌텐도, 쿠키런).
5. **이 환경에서 되는 것과 안 되는 것이 있다.** 픽셀·복셀·로우폴리·툰 3D·아이소·네온·잉크 만화·수채는 파일 하나로 잘 만든다. 실사 3D는 만들지 않는다(8장).

## 1. 고르는 순서 (장르 추천 때마다)

1. **세계를 먼저 정한다(3장).** 단원 개념이 "행동"이 되는 장소·직업·사건을 고른다. 과목이 아니라 그 세계가 그림체를 부른다.
2. **못 쓰는 계열을 지운다(5장).** 대상은 최근 3개 게임의 계열과 같은 과목 최근 3개 게임의 계열이다. `docs/그래픽_기록.md`의 "계열·6축 표"를 본다.
3. **남은 계열에서 이 세계에 맞는 스타일을 고른다(4장).** 과목 조건표(2장)를 지키는지 확인한다.
4. **스타일 카드를 쓴다(1-2).** 6축을 한 줄씩 적는다. 최근 3개 게임 각각과 **6축 중 4축 이상** 다르게 한다.
5. **후보 5개 중 1개는 탐험 칸이다(5-3).**
6. **후보 5개마다 미리보기 그림 1장을 그린다(6장).** 교사는 글이 아니라 그림을 보고 고른다.

### 1-1. 6축

| 축 | 고를 것(예) |
|---|---|
| ① 모양 | 둥글고 말랑 / 각지고 기하학 / 뾰족하고 거침 / 손떨림·삐뚤빼뚤 / 블록·격자 / 길쭉한 고무호스 |

| ③ 팔레트 | 파스텔 / 고채도 원색 / 채도 낮춘 저녁색 / 어두운 바탕 + 빛나는 색 / 흑백 + 한 색 / 세피아 / 흙·자연색 / 오방색 / 제한 16색 |
| ④ 빛 | 한낮 위에서 / 아침 옆빛 / 노을 역광 / 밤 + 빛 구멍(등불·모닥불) / 실내 창빛 / 네온 / 물속 빛줄기 / 빛 없음(평면 도안) / 안개 확산광 |

```
세계:       예) 하늘 우편 항로(기체 단원: 데우면 부피가 늘어 떠오른다)

```

## 2. 과목이 그림에 요구하는 조건 (스타일 목록이 아니다)

과목마다 그림체를 2~3개로 정해 두면 같은 과목을 다시 만들 때 그 안에 갇힌다. 그래서 이 표에는 **그림이 꼭 해야 할 일**만 적는다. 이 조건을 채우면 카탈로그 24종 어느 것이든 후보가 된다.
오른쪽 칸은 같은 조건을 **서로 다른 계열로** 채운 예시일 뿐이다. 이 칸에서 고르지 말고 4장 전체에서 고른다.

| 단원 모양 | 그림이 꼭 해야 할 일 | 피할 것 | 같은 조건, 다른 계열의 예 |
|---|---|---|---|
| 국어: 긴 지문·이야기·대화 | 글을 오래 읽어도 편한 읽기 판(25px 이상, 바탕과 대비 강하게), 인물 표정이 감정을 전함(6종 이상), 장면 전환이 이야기 흐름을 보여 줌 | 움직이는 배경 위에 판 없이 얹은 긴 글, 읽는 동안 시간 압박 | 큰 초상 대화창 픽셀 마을 / 채도 낮춘 그림책 페인터리 / 인형극 무대 디오라마 |
| 국어: 낱말·문법·맞춤법 | 글자가 물건처럼 집고 맞출 수 있게 크고 또렷함, 자모가 정확한 본문 글꼴 | 획이 뭉개지는 붓·손글씨 글꼴로 문제 글 | 글자 블록 복셀 / 사탕 글자 일러스트 / 목판 활자 |

| 사회: 지도·지리·지역 | 위에서 위치 관계가 읽힘(방위·축척 단서), 지형 높낮이 구분 | 1인칭만으로 위치 판단 | 위에서 보는 픽셀 마을 / 로우폴리 섬 / 민화식 옛 지도 / 떠 있는 섬 |

## 3. 세계 먼저 정하기

과목에서 바로 그림체로 가면 "과학 = 실험실", "역사 = 한지"로 굳는다. 사이에 **세계**를 둔다.

1. **개념 → 동사:** 단원의 핵심 개념이 무엇을 하게 만드는가. 예) 기체는 데우면 부피가 늘어난다 → "띄운다·부풀린다".
2. **동사 → 직업·장소 3개 이상:** 장소의 크기를 서로 다르게 고른다(책상 위 미니어처 / 마을 / 하늘 / 바닷속 / 몸속 / 우주 / 옛날).
   - 예) 띄운다 → 열기구 우편배달(하늘) · 잠수정 공기 탱크(바닷속) · 빵집 반죽 부풀리기(가게) · 풍선 개구리 마을(작은 생물 눈높이)
3. **세계 → 그림체:** 세계마다 어울리는 스타일을 4장에서 찾는다. 같은 단원이라도 세계가 다르면 그림체가 갈린다.
   - 바닷속 → P5 HD-2D
   - 개구리 마을 → T4 작은 생물 눈높이
   - 빵집 → P2 픽셀 단면도
4. 장르 후보 5개는 **세계도 서로 다르게** 한다.

## 4. 계열 6개 · 스타일 24종

각 카드: **기준작**(영상에서 확인, 느낌만) · **보이는 특징 5가지** · **만드는 법**(가이드 레시피 번호와 숫자) · **UI·글꼴** · **기본 6축** · **어울리는 세계** · **피할 것**.
기본 6축은 출발점이다. 빛·팔레트·시점을 바꾸면 같은 스타일도 다른 게임이 된다.

### P. 픽셀 계열

**P1. 위에서 보는 픽셀 마을**
- 기준작: Witchbrook(위에서 보는 정교한 마을)
- 특징: 작은 타일 격자 · 3/4 위 시점 · 지붕·나무가 겹쳐 깊이 · 빽빽한 소품(화분·울타리·간판) · 사람들이 길을 걸음
- 만드는 법: 가이드 4.10. 320×180 → 정수 4배, 팔레트 32색 안팎, 타일 16px, 캐릭터 16×24, 외곽선은 검정 대신 옆 색의 어두운 단계
- UI·글꼴: 픽셀 창(1px 테 2겹 + 9조각) · Galmuri11
- 기본 6축: 블록·격자 / P1 / 제한 32색 따뜻한 / 한낮 위에서 / 3/4 / 픽셀 창
- 어울리는 세계: 마을 지도, 장터, 학교, 동네 탐험, 지역 조사
- 피할 것: 정수가 아닌 배율(번진 점), 점과 매끈한 그림을 한 화면에 섞기

**P2. 픽셀 단면도 경영**
- 기준작: 카이로소프트 게임들(게임 개발·백화점·편의점·라멘·던전마을 스토리)
- 특징: 건물을 옆에서 자른 단면 · 방마다 다른 일 · 작은 사람 수십 명이 오가며 머리 위에 아이콘 말풍선 · 숫자가 톡톡 튀어 오름 · 위아래 띠 UI
- 만드는 법: 4.10 + 방 격자(방 48×32px). 사람은 8×12px 걷기 2프레임, 머리 위 아이콘 8px. "+12" 같은 숫자 팝업은 픽셀 글꼴
- UI·글꼴: 위 한 줄 정보 띠 + 아래 한 줄 메뉴 띠(픽셀 창) · Galmuri11
- 기본 6축: 블록·격자 / P2 / 고채도 16색 / 실내 고른 빛 / 단면도 / 픽셀 창
- 어울리는 세계: 가게·공장·학교·병원·우체국 경영, 몸속 단면, 개미굴, 지층
- 피할 것: 방이 비어 있는 화면, 사람이 멈춰 있는 화면

**P3. 밤과 등불 픽셀**
- 기준작: Vampire Rancher, The Last Spell, Haunted Chocolatier의 밤

## 5. 돌려쓰기 규칙

### 5-1. 못 쓰는 계열
1. **최근 3개 게임**의 계열은 쓰지 않는다.
2. **같은 과목 최근 3개 게임**의 계열도 쓰지 않는다. 같은 과목을 오래 만들수록 아직 안 쓴 쪽으로 밀려나므로, 반복해서 만들수록 다양해진다.
3. 두 규칙으로 남은 계열이 3개보다 적으면, 3개가 될 때까지 제외를 푼다.
   - 전체 최근 3개 중 오래된 게임부터 푼다(같은 과목 돌려쓰기를 더 지키기 위해).
   - 그래도 모자라면 같은 과목 쪽에서 오래된 게임부터 푼다.
   - **직전 게임의 계열은 풀지 않는다.**
4. 계열은 화면 면적이 가장 큰 렌더링으로 정한다(예: 수채 배경 + 셀음영 전경은 손그림 H).
5. 계열 표에 없는 옛 플랫 벡터(2026-09 게임들)는 카탈로그 밖이다. 다시 쓰지 않는다.

### 5-2. 6축과 UI 재질
- 최근 3개 게임 각각과 **6축 중 4축 이상** 다르다.
- **UI 재질**은 직전 2개 게임과 다르다.
- 크림 종이 + 놋쇠 + 빨간 도장·밀랍 조합은 쓰지 않는다(기록부 "되풀이된 틀").

### 5-3. 후보 5개
- 5개는 **스타일이 모두 다르고, 계열은 3개 이상**이다. 계열이 3~4개뿐이면 같은 계열 두 후보는 6축 중 4축 이상 다르게 한다.
- 5개 중 1개는 **탐험 칸**이다. 다음 중 하나여야 한다.
  - 저장소에서 아직 한 번도 쓰지 않은 스타일(기록부 계열 표 기준)
  - 그 과목과 의외의 조합(예: 국어 + 네온 복셀, 역사 + 고무호스 만화)
- 탐험 칸도 2장 과목 조건은 지킨다. 어색하면 교사가 미리보기를 보고 고르지 않으면 된다.

## 6. 후보마다 미리보기 그림 1장

장르 추천 표에 글만 쓰지 않는다. 후보 5개마다 **그 스타일로 그린 대표 장면 1장**을 함께 보낸다.
- 1280×720 정지 그림 1장이다. 세계 + 주인공 + 문제가 놓일 물건 + UI 조각 하나(단추나 게이지)를 넣는다.
- 키 아트보다 가볍게 만든다(한 장에 코드 150~400줄). 6축이 눈에 보이면 된다.
- 문제·정답은 아직 넣지 않아도 된다. 대신 "이 물건에 문제가 나온다"는 자리를 보여 준다.
- 5장을 한 장의 비교판(2×3 칸, 6번째 칸에는 최근 3개 게임 축소판)으로도 묶어 보낸다.
- 교사가 고르면 그 미리보기가 키 아트의 출발점이 된다.
- 요청서가 "끝까지 알아서"이면 1순위로 진행하고, 보고에 미리보기 5장을 함께 낸다.

## 7. 성장이 보이는 세계

점수와 별만으로 보상하지 않는다. **맞힐 때마다 세계가 실제로 바뀌게** 한다.
- 예: 구름이 걷힘 · 꽃밭이 채워짐 · 불이 켜짐 · 건물이 늘어남 · 무너진 다리가 복구됨 · 손님이 늘어남 · 흑백이 색으로 바뀜
- 변화는 다음 세 곳에 보인다.
  - 플레이 화면(정답 직후 0.5~1초 안에)
  - 스테이지 선택 화면(되살린 곳은 밝고, 아직인 곳은 구름·어둠·흑백)
  - 결과 화면(오늘 되살린 세계 전경)
- 화면 틀도 이 변화가 보이는 쪽으로 고른다(가이드 6.9의 구름 걷힘 지도, 복구된 세계 결과).
- 오답은 세계를 망가뜨리지 않는다. 변화가 늦게 올 뿐이다(규칙: 실패는 아프되 짜증 나지 않게).

## 9. 아이 눈높이 기준 (채점표 11번)

닌텐도·쿠키런 화면에서 뽑은 다섯 가지다. 가이드 9장 11번으로 채점한다.
1. **실루엣:** 화면을 1/4(320×180)로 줄여도 주인공과 조작 대상이 모양만으로 구분된다.
2. **원색 초점:** 시선이 가야 할 곳(조작 대상, 정답 연출)이 화면에서 가장 채도가 높다.
3. **과장된 표정:** 눈 크기가 바뀌고 입 모양이 크게 달라진다. 표정이 멀리서도 읽힌다.
4. **보상 공개:** 시상대, 배지, 도감 등록, 세계 복구처럼 "짠" 하고 보여 주는 장면이 있다. 확률형 뽑기는 넣지 않는다.
5. **모으기:** 도감·스티커·수집 칸처럼 모은 것을 다시 보는 곳이 있다.
