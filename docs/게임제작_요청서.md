> 학습지·단원평가 PDF를 함께 첨부하세요. 빈칸은 비워 둬도 됩니다(기본값으로 진행).

- **학년 / 학기 / 과목:**
- **단원 / 주제:** (예: 2. 올바른 문장으로 글을 써요)
- **첨부 자료:** (예: 학습지 20문항 PDF)
- **문항 구성:** 기본 = 학습지 문항 + 변형 10문항, 3스테이지
- **핵심 성취기준 / 학습 목표:** (모르면 "찾아서 제시해 줘")
- **수업 단계:** 도입 / 전개 / 정리 / 평가
- **학생 기기:** 개인 태블릿 / 개인 노트북(크롬북) / 교실 TV 한 대
- **게임 장르:** "추천해 줘" 또는 직접 지정 (참고할 게임이 있으면 적기)
- **피하고 싶은 장르:** (최근에 쓴 형식)

## 자주 쓰는 짧은 요청 (수정할 때)
