# 그래픽 기록부 (docs/그래픽_기록.md)

> 클로드는 이전 게임이 어떻게 생겼는지 기억하지 못한다. 그래서 같은 틀이 옷만 바꿔 되풀이됐다.
> 새 게임을 설계하기 전에 이 기록부를 읽고, 다 만든 뒤 맨 위에 한 줄을 더한다(`CLAUDE.md` 3장·5장).

## 비교하는 9가지

| # | 속성 | 적는 법 |
|---|---|---|
| 1 | 장르·핵심 조작 | 장르 + 학생 손이 하는 일(예: 러너 · 점프로 정답 문 고르기) |
| 2 | 시점·카메라 | 옆에서 / 위에서 / 3/4 / 아이소메트릭 / 1인칭 / 정면 무대 + 카메라 움직임 |
| 3 | 렌더링 | 플랫 벡터 / 2D 카툰 셀음영 / 2.5D / 3D 툰 / 픽셀 / 페인터리 / 종이 공작 / 네온 / 미니멀 선화 |
| 4 | 주조색 | 화면을 차지하는 색 2~3개 |
| 5 | 빛·시간대 | 광원 방향과 시간(오후 해, 노을 역광, 밤 조명, 실내 등불, 없음) |
| 6 | UI 재질 | 흰 카드 / 나무 / 놋쇠 / 법랑 / 종이 / 사탕 / 유리·네온 / 픽셀 창 등 |
| 7 | 글꼴 | 제목 / 본문 |
| 8 | 타이틀·스테이지 선택 | 첫 화면 구성 + 스테이지 고르는 화면 구성 |
| 9 | 문제 제시·답 입력 | 문제가 나오는 곳 + 답하는 손동작 |

**규칙:** 새 게임은 최근 3개 게임, 시안 2개, 같은 단원 게임, 같은 장르 게임 각각과 **9가지 중 6가지 이상** 다르다. **8번과 9번은 반드시 다르다.** 아래 "되풀이된 틀"은 쓰지 않는다.
**그림체는 따로 한 번 더 본다:** 아래 "계열·6축 표"로 계열 돌려쓰기와 6축(4축 이상 다름)을 확인한다(`docs/스타일_카탈로그.md` 5장).

## 되풀이된 틀 (쓰지 않는다)

| 틀 | 쓴 게임 |
|---|---|
| 타이틀 A: 왼쪽 그림 장면 + 오른쪽 흰 카드(제목·설명·이름칸·시작·하는 법·체크박스) | 어린이 방송국, 날씨 상자 실험실 |
| 타이틀 B: 가운데 큰 외곽선 글자 로고 + 이름칸 + 알약 단추 한 줄(시작·하는 법·상점) + 체크박스 | 무지개 골목, 말이 되는 섬, 달려라 경제 쿠키, 동그라미 왕국 |
| 타이틀 C: 가운데 큰 글자 로고 + 부제 + 명찰형 이름 카드(아이콘·영어 작은 글씨·밑줄 칸) + 주황 시작 단추(Enter) | 분수 컬링, 인터뷰 카드 배틀, 분수 급행열차 |
| 스테이지 선택: 카드 3~5장 가로 배열(잠금 표시) | 말이 되는 섬, 달려라 경제 쿠키, 분수 컬링, 분수 급행열차(노선 카드) |
| 문제 제시: 화면 한쪽을 늘 차지하는 문제 패널 | 어린이 방송국, 날씨 상자 실험실, 기후 벨트 지구본, 고려 활자 인쇄소 |
| 답 입력: 숫자 위아래 단추(스테퍼) + 출발·던지기 | 분수 컬링, 분수 급행열차 |
| 답 입력: 세로 목록 보기 단추 ①~⑤ | 날씨 상자 실험실, 어린이 방송국, 테트리스 퀴즈 외 다수 |
| 스테이지 선택: 종이 지도 위 핀 + 탈것이 점선 따라 이동 | 울림 밴드 월드 투어(섬 핀·버스), 분수 급행열차(노선도) |
| 스테이지 선택: 아래→위로 쌓인 세로 단계(위로 갈수록 어려움) | 빛줄기 서커스(줄사다리 발판), 열기구 우편 비행(세로 분류함) |
| 그림체: 3단 셀음영 + 진한 외곽선 + 종이 결을 모든 게임에 덮어씌움(이름만 수채·종이 공작·네온) | 빛줄기 서커스, 지구 궤도 관제사(3D 판), 울림 밴드, 열기구 우편 비행 |
| UI 재질: 크림 종이 + 놋쇠 테·명판 + 빨간 도장·밀랍 | 빛줄기 서커스(신청서·놋쇠 명판·잉크 도장), 지구 궤도 관제사(놋쇠 오러리·밀랍), 열기구 우편 비행(항공우편 종이·놋쇠 계기·밀랍) |
| 문제 제시: 줄·집게에 매달린 종이 | 빛줄기 서커스(밧줄 집게 신청서), 울림 밴드(집게 큐 시트), 열기구 우편 비행(바구니 줄에 매단 편지) |
| 안내: 화면 한쪽에 선 2~2.5등신 동물·로봇 안내역이 힌트·해설을 말함 | 빛줄기 서커스(너구리 단장), 울림 밴드(부엉이 매니저), 지구 궤도 관제사(보조 로봇), 열기구 우편 비행(우편 비둘기) |
| 결과: 종이 일지·기록지·프로그램 책 | 빛줄기 서커스(공연 프로그램 책), 지구 궤도 관제사(관제 일지), 열기구 우편 비행(배달 일지) |
| 타이틀: 한쪽에 줄로 매단 "눌러서 ○○!" 판 + 아무 곳이나 눌러 시작 | 빛줄기 서커스(밧줄 전구 글자판), 열기구 우편 비행(끈에 매단 판) |

안내역 캐릭터를 없애라는 뜻은 아니다. 힌트를 **누가·어디서** 전하는지를 바꾼다. 예를 들면 주인공이 직접 반응하거나, 손님·상대가 말하거나, 세계 속 물건(만화 칸·청사진 메모·픽셀 창)에 나타나게 한다.

**지금 상태로 계산한 다음 게임의 제외 계열** (새 게임을 올리면 다시 계산한다)
- 전체 최근 3개(열기구 H · 울림 밴드 H · 관제사 T) → H, T 제외
- 과학 다음 게임: 같은 과목 최근 3개도 H·H·T → **P, B, I, G에서 고른다**
- 수학 다음 게임: 같은 과목 최근 3개(빛줄기 G · 옛 플랫 · 옛 플랫) → G도 제외 → **P, B, I**
- 국어 다음 게임: 같은 과목 최근 3개(인터뷰 카드 I · 천지인 옛 플랫 · 어린이 방송국 옛 플랫) → I도 제외 → **P, B, G**
- 사회 다음 게임: 같은 과목 최근 3개(고려 활자 I · 무지개 골목 옛 플랫 · 달려라 경제 쿠키 I) → I도 제외 → **P, B, G**
- **아직 한 번도 쓰지 않은 계열:** P 픽셀(수학 코스터의 일부 픽셀 글꼴 빼고), B 블록·다각형 → 탐험 칸 1순위

## 새 줄 쓰는 법
- 허브에 등록하는 날, 표의 맨 위(시안 줄 아래)에 한 줄을 더한다. **계열·6축 표에도 맨 위에 한 줄**을 더하고, "다음 게임의 제외 계열"을 다시 계산한다.
- 8·9번은 다음 게임이 피할 수 있게 **구성까지** 적는다(예: "타이틀: 세계를 날아가는 카메라 끝에 역 간판 로고 / 스테이지: 선로 지도 위 역 핀").
- 새로운 틀이 두 게임 이상에서 되풀이되면 "되풀이된 틀"에 올린다.
