# 연출 점검 (docs/연출_점검.md)

> 그림이 좋아도 **행동의 원인과 결과가 즉시 느껴지지 않으면** 밋밋하다. 이 문서는 다 만든 게임을 "사건" 단위로 돌아보는 방법이다.
> 하는 때: 제작이 끝나고 검증 전에 한 번. 하는 사람: 만든 당사자가 아니라 `.claude/agents/juice-critic.md` 서브에이전트.
> 목표는 효과를 많이 넣는 것이 아니다. **의도가 분명하고, 일관되고, 학생이 "내가 뭘 했더니 뭐가 됐다"를 바로 아는 상태**다.
> 그래픽 채점표(가이드 9장)가 "보기에 좋은가"라면, 이 점검은 "느껴지는가"다.

---

## 1. 사건을 흐름으로 본다

사건 하나를 점이 아니라 여섯 단계의 흐름으로 본다. 어느 단계가 비었는지 찾는다.

```
입력 → 준비(anticipation) → 행동 → 변화 → 결과 → 정착(recovery)
```

예) 분수 급행열차 "출발" 레버:
입력(레버 누름) → 준비(레버가 젖혀지고 기적이 울림, 0.3초) → 행동(기차가 움직임) → 변화(보낼 화차가 떨어져 나감) → 결과(정답 판정, 도장) → 정착(남은 화차가 역에 멈추고 다음 운송장이 옴)

**가장 흔한 구멍:** 준비와 정착이 없다. 누르자마자 결과가 뜨고, 결과가 뜨자마자 다음 문제가 온다. 학생은 무슨 일이 있었는지 못 본다.

## 2. 우리 게임의 사건 목록 (전투 용어가 아니라 이것으로)

| 사건 | 중요도 | 있어야 할 것 |
|---|---|---|
| 단추·레버 누름 | 일반 | 0.1초 안에 눌림(3px) + 소리. 놓을 때 되돌아옴. 못 누르는 단추는 흐리고 눌러도 꿈쩍 않음 |
| 값 고르기·끌기·조준 | 일반 | 집으면 커지고 그림자가 커짐, 놓으면 살짝 튕김. 지금 값이 세계에 **즉시 미리 보임**(화차 수를 바꾸면 기차가 바뀜) |
| 정답 | 중요 | 세계가 반응한다(문이 열림, 기차가 떠남, 꽃이 핌). 캐릭터 표정. 보상 숫자 올라감. **0.6초 안**에 조작 가능 |
| 한 번에 정답·콤보 | 중요 | 정답 연출 + 한 가지 더(금빛, 콤보 숫자 커짐). 가장자리 빛은 콤보 3부터 |
| 오답 | 중요 | 대상만 흔들림 + 낮은 소리 + 캐릭터가 아쉬운 표정으로 힌트. **화면 흔들림·빨간 번쩍임·넉백 금지** |
| 힌트 받음 | 일반 | 힌트가 말풍선으로 "나타나는" 과정(0.2초). 힌트 쓴 횟수 표시가 줄어듦 |
| 스테이지·노선 열림 | 중요 | 잠금이 풀리는 과정이 보임(자물쇠 흔들림 → 열림 → 빛). 카메라가 새 스테이지로 감 |
| 보스·마지막 문제 등장 | 클라이맥스 | 일반 문제와 **체감이 다름**: 음악 바뀜, 화면 어두워짐, 등장 연출 1~1.5초, 이름 띠 |
| 스테이지 완주·승리 | 클라이맥스 | 마지막 정답 임팩트 → 짧은 여운(0.5초) → 결과 화면이 **쌓이듯** 나옴(기록 하나씩) → 보상 |
| 실패·다시 하기 | 중요 | 벌이 아니라 "다시 해 보자". 캐릭터가 격려. 즉시 다시 시작 단추 |
| 결과·오답 노트 열기 | 일반 | 책·두루마리가 펼쳐짐. 숫자는 카운트업(보상 숫자만) |
| 화면 전환 | 일반 | 장르 연출(가이드 6.8) 0.4~0.6초. 흰 깜빡임 금지 |

**학습 숫자와 보상 숫자를 구분한다.** 분수·계산 결과·측정값처럼 **학습 내용인 숫자는 즉시 확정 표시**한다(또르르 바뀌면 틀린 값이 잠깐 보여 혼란). 코인·점수·콤보 같은 **보상 숫자만** 카운트업·튕김을 쓴다.

## 3. 강도는 중요도에 비례한다

| 등급 | 사건 | 허용 | 금지 |
|---|---|---|---|
| 일반 | 단추, 값 바꾸기, 힌트, 전환 | 소리 + 작은 움직임 + 입자 몇 개 | 화면 흔들림, 확대, 히트스톱 |
| 중요 | 정답, 오답, 스테이지 열림 | 세계 반응 + 캐릭터 표정 + 입자 12~20 + 짧은 확대(5%) | 1초 넘는 연출, 조작 막힘 0.6초 초과 |
| 클라이맥스 | 보스 등장, 완주, 승리 | 히트스톱 60ms, 흔들림 0.25초, 색종이, 음악 전환, 1~2초 연출 | 반복 시 건너뛸 수 없음 |

- 한 판에 클라이맥스는 **2~3번**이다(스테이지 끝, 보스, 최종). 모든 정답에 클라이맥스 연출을 쓰면 정작 클라이맥스가 묻힌다.
- 오답은 중요 사건이지만 **강도는 일반 수준**이다. 초등학생에게 오답 연출은 벌이 아니라 "다시"의 신호다.

## 4. 반복 플레이 기준 (숫자)

한 판에 문항이 30개다. 정답 연출이 2초면 학생은 수업 중 60초를 기다린다.
- 정답 연출 중 **조작이 막히는 시간 0.6초 이내**. 연출이 더 길면 뒤쪽은 다음 조작과 겹쳐 돌아간다.
- 같은 연출이 **5번째부터는 짧아진다**(입자 절반, 말풍선 생략). 콤보가 쌓이면 다시 커진다.
- 클라이맥스 연출(1~2초)은 **아무 곳이나 눌러 건너뛰기**가 된다. 결과 화면이 쌓이는 연출도 마찬가지.
- 같은 효과음이 3번 연속 똑같이 나지 않게 음높이를 조금씩 바꾼다.
- 저사양 모드에서는 입자·흔들림을 줄이되 **단계(준비·정착)는 남긴다**.

## 5. 중복·과잉 깎기

점검자는 아래를 찾아 **유지 / 통합 / 삭제** 중 하나를 제안한다.
- 같은 정보를 두 번 알리는 연출(정답 소리 + "정답!" 글자 + 캐릭터 대사 + 별 + 도장 = 다섯 번). 중요도에 맞게 두세 가지로 줄인다.
- 서로 시선을 뺏는 연출(왼쪽에서 말풍선이 뜨는데 오른쪽에서 코인이 터짐). 순서를 두거나 하나를 뺀다.
- 역할이 겹치는 UI(진행 점과 "3/10" 글자, 두 군데의 코인 표시).
- 스타일이 다른 요소(이 게임만 둥근 단추인데 결과 창만 각진 흰 창).
- 안 쓰는 코드·효과·소리.

## 6. 로직은 있는데 표현이 없는 사건 (가장 먼저 찾을 것)

코드에 판정은 있지만 화면·소리로 전달되지 않는 사건이 가장 고치기 쉽고 효과가 크다.
- 정답인데 숫자만 바뀜 (세계가 반응하지 않음)
- 화차·블록·카드가 "떨어져 나가는" 순간이 바로 사라짐 (과정 없음)
- 스테이지가 열렸는데 카드의 자물쇠 그림만 바뀜
- 코인을 얻었는데 코인 숫자만 바뀜 (날아가서 쌓이는 과정 없음)
- 보스가 나왔는데 일반 적과 똑같이 걸어 들어옴
- 다 풀었는데 결과 창이 뚝 뜸 (여운 없음)
- 단추를 눌렀는데 아무 반응 없이 화면이 바뀜

## 7. 점검 보고 양식

내부 분석(1~6장)은 길어도 되지만, **교사에게 보고하는 것은 아래 3단 정리만**이다.

```
연출 점검 — <게임 이름>
1. 즉시 고치면 효과가 큰 것 (로직은 있는데 표현이 없는 사건)
   - (사건) 지금 → 제안. 강도 등급. 예상 시간
2. 적은 비용으로 좋아지는 것
   - …
3. 나중에 다듬을 디테일
   - …
깎을 것 (유지/통합/삭제)
   - …
반복 플레이 확인: 정답 연출 n초 · 건너뛰기 있음/없음 · 5번째부터 짧아짐 있음/없음
```

각 제안에는 **왜 이 게임에서 체감이 큰지** 한 줄을 붙인다. 체감이 작거나 과한 효과는 제안하지 않는다.

## 8. 분수 급행열차 점검 예시

(`juice-critic`가 2026-10-05에 실제로 점검한 결과. 새 게임 점검의 본보기로 둔다.)

```
연출 점검 — 분수 급행열차 (3-2 수학 분수)
사건 흐름표
- 출발 레버 | 일반 | 준비 없음 | 마우스 :active로만 젖혀짐, 소리 없음, Enter로 누르면 안 움직임 | 부족
- 값 바꾸기 | 일반 | — | 화차 수 바꾸면 기차가 즉시 다시 조립 + 튕김 + clank, 읽기창 즉시 확정 | 맞음
- 정답 | 중요 | 준비 없음 | 입자 40개 + 전체 화면 흰 번쩍임 + "+40" + 코인 비 + whistle + 0.35초 뒤 cheer + 수달 happy + 깃발 + 말풍선 + 레버 빛 + 오른쪽 단추 | 과함(같은 정보 7겹)
- 콤보 | 중요 | 변화 없음 | 글자와 HUD 🔥n뿐. sfx.combo()가 있는데 호출 0회 | 부족
- 오답 | 중요 | 정착 약함 | **화면 전체 흔들림** + 열차 흔들림 + buzz + 신호등 빨강 + 수달 worry + 힌트(0초에 완성형) + 잠금 1.2/2.2초, 잠금 풀릴 때 신호 없음 | 과함(화면 흔들림 금지 위반)
- 출발·화차 분리 | 중요 | 변화(분리 순간) 없음 | lever + toot, 조작판·말풍선 즉시 사라짐, 남을 화차는 소리·틈 없이 제자리, 3.4초 이동 건너뛰기 없음 | 부족
- 노선 완주 | 클라이맥스 | 여운·쌓임 없음 | 별·숫자·대사·단추가 0초에 한 번에, 정답과 같은 bell+cheer. sfx.starN() 호출 0회 | 부족(정답과 체감 차이 없음)
- 노선 열림 | 중요 | 전 단계 없음 | 노선도에 돌아오면 이미 열려 있음. sfx.unlock() 호출 0회 | 부족
- 최종 결과 | 클라이맥스 | 쌓임 없음 | 한 번에 표시, 또 cheer. sfx.win() 호출 0회 | 부족

1. 즉시 고치면 효과가 큰 것
   - (오답) 화면 전체 흔들림 FX.shake 삭제, 열차만 흔들림 · 일반 · 10분 · 오답은 벌이 아니라 "다시" 신호. 교실에서 틀린 아이 쪽으로 시선을 모으는 연출이다
   - (화차 분리) depart에서 0.45초 뒤 이음새에 clank + 연기 + 남은 화차가 살짝 뒤로 밀림 · 중요 · 30분 · "전체 중 보낼 몫만 떠난다"가 이 게임의 분수 그림인데 그 순간이 표식 없이 지나간다
   - (노선 완주) 띠 → 별 하나씩 0.3초 간격(starN) → 기록 세 칸 순서대로 → 대사 → 단추. 총 1.5초, 아무 곳이나 눌러 즉시 완성 · 클라이맥스 · 30분 · 한 판에 5번뿐인 클라이맥스가 정답 소리로 뚝 뜬다
   - (노선 열림) 노선도 진입 때 방금 끝낸 노선 별이 채워지고, 다음 노선 자물쇠가 흔들리다 풀림 + unlock 소리 + 입자 12개 · 중요 · 30분 · 5개 노선 진행이 성장 축인데 열리는 과정이 한 번도 안 보인다
   - (코인) HUD 숫자가 코인이 날아가기 전에 먼저 바뀜 → 코인이 도착하는 순간 올리고 0.15초 튕김 · 중요 · 30분 · 원인(코인 도착) 뒤에 결과(숫자)가 와야 "내가 벌었다"가 된다
2. 적은 비용으로 좋아지는 것
   - (출발 레버) 레버 젖혀짐 + lever 소리 → 0.25초 뒤 판정. Enter도 같게 · 10분
   - (콤보) 콤보 2 이상이면 cheer 대신 sfx.combo(n) · 10분 · 쌓일수록 소리가 올라감
   - (힌트) 정답과 같은 whistle 대신 bell · 10분
   - (잠금 해제) 글자만 바뀌는 자리에 tick 2번 + 조작판 테두리 0.2초 밝힘 · 10분
   - (정답 입자) 기관차 머리가 아니라 보낼 화차 위에 16~20개 · 10분
   - (sort·nums 정답) 손님이 순간이동 대신 board처럼 뛰어 타게 · 30분
   - (효과음 변주) 음높이 ±4% · 10분 · 30번 똑같은 기적이 난다
3. 나중에 다듬을 디테일
   - 역 이동 3.4초: 1초 뒤 아무 곳이나 누르면 빨리 감기 · 30역이면 100초
   - 최종 결과: 점수 카운트업 0.8초 + sfx.win + 새 기록 입자
   - 정답 뒤 힌트 단추가 흐려지지 않음, 조작판·말풍선이 전환 없이 끊김, 오답 잠금 2.2초는 1.6초 검토

깎을 것
   - 정답의 전체 화면 흰 번쩍임 · 삭제(또는 콤보 3부터만) · 입자·깃발·글자·whistle이 이미 정답을 말한다
   - 정답 whistle + cheer · 통합(whistle 하나) · cheer는 완주·최종에서 또 쓰여 클라이맥스 소리를 뺏는다
   - 오른쪽 "다음 역" 단추 + 레버 "다음 역" 빛 · 통합(레버가 있는 종류는 레버만) · 같은 일을 하는 단추가 둘이라 시선이 갈린다
   - 미사용 효과음 12개(door·skill·reward·heal·enter·deal·play·slot·flip·crane·hover·wrong) · 삭제 / starN·unlock·combo·win · 유지(1·2번에서 씀)

반복 플레이: 정답 뒤 조작 막힘 0초 · 역 이동 3.4초×30 건너뛰기 없음 · 오답 잠금 1.2/2.2초 · 5번째부터 짧아짐 없음 · 효과음 변주 없음
클라이맥스 시퀀스: 마지막 정답(1번 정답과 똑같음) → 종착역 이동 3.4초 → 기차가 멈추는 장면·기적 없이 패널이 뚝 뜸 → 노선도(이미 열려 있음) → 최종 결과(한 번에). 가장 큰 문제: 마지막 정답이 첫 정답과 체감이 같다
```
